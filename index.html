Case files

A case is saved in this browser automatically. Save case file (.json) is the case data only — small and quick, and it is what Save to Google Drive uploads. Save case bundle (.zip) carries the case data and every attachment, including scanned PDFs, in one file — use this for the archival copy and for sending a whole case to another officer. Opening a bundle restores the attachments.

Attachments are held in the browser's IndexedDB, which is far roomier than the few megabytes of ordinary browser storage, so scanned depositions and charge sheets can be attached and kept. They are not written into the .json file — a scanned PDF base64-encoded into JSON would be about a third larger again and would fill the browser store — which is exactly why the bundle exists.

My assignments — one officer, several cases

An officer is often appointed Inquiring Authority or Presenting Officer in more than one case at the same time. This keeps them apart: enter the name and each case in which that officer holds a role is listed separately, with the role, the employee charged, the assignment order and whether the assignment letter has been filed. Opening one does not disturb any other.

Google Drive

Create an OAuth client ID of type "Web application" in Google Cloud Console, enable the Google Drive API, add this page's origin as an authorised JavaScript origin, and paste the client ID here. It is stored only in this browser.

Separate folder per case. Every case gets its own new folder — one case is never filed inside another case's folder, and an existing folder is only reused for the same case on a later save. Create this case's Drive folder now makes the folder and its subfolders straight away, before any document is uploaded, so you can also drop papers into it by hand from your phone or computer.

The folder plan. The case is filed as <top folder> / <work folder> / <branch> / <Name (Employee ID)>, and inside that case folder there is one subfolder for each kind of paper — charge sheet, IO-PO assignment letters, PO brief, IO report, prosecution depositions, defence depositions, daily order sheets, defence statement, general examination, correspondence and other. The case data and the case bundle sit in the case folder itself; every attachment goes into its own subfolder. Press Show the folder plan to see it. Saving again updates the same folders and files.

What goes up. The case data as <employee>_<case id>.json, the case bundle as <employee>_<case id>.zip, and each attachment in its subfolder.

Where the file goes. The app creates a folder of the name given above — in your My Drive, at the top level — and puts the case file inside it as <employee>_<case id>.json. Saving the same case again updates that same file instead of making a duplicate. The app asks for the full Drive permission, because to file a case inside the folder you already keep it has to be able to see and write into your own folders. It uses that only to find the top folder, create the case folders and upload the papers. If you would rather not use Drive, Save case file downloads the JSON and you can move it into any Drive folder yourself.

    Assignment as Presenting Officer

    Keep the letter by which the Presenting Officer's work was assigned with the case. It is filed with the case file, travels in the case bundle, and is listed in the Presenting Officer's brief.

    Attach documents

    Scanned PDFs can be attached directly. A document photographed page by page goes through the Photographs of a document card below, which turns the pictures into one multi-page PDF so it is filed as a single paper. Either way the bytes go to the browser's IndexedDB, which holds far more than ordinary browser storage, and they travel with the case in the case bundle (.zip).
